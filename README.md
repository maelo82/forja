# Forja Entrenamiento

Libreta de entrenamiento para el móvil: fuerza, carrera y natación en una sola app.

## Qué hace
- Rutinas por días con más de 100 ejercicios explicados y alternativas si la máquina está ocupada.
- Registro de series con descanso editable, aviso al terminar y pantalla siempre encendida.
- Progresión de peso, máximo estimado por ejercicio, calculadora de discos y seguimiento del peso corporal.
- Historial, gráficas de progreso y copia de seguridad en archivo.
- Funciona sin internet y se instala como app (PWA). Los datos se guardan en el propio móvil.

## Tecnología
- HTML, CSS y JavaScript sin librerías.
- Service worker para uso sin conexión y notificaciones.
- Publicada con GitHub Pages y empaquetada como APK de Android con PWABuilder.

## Estado
Versión de prueba (0.3.0) con un grupo pequeño de testers.
